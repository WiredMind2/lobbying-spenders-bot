### US-003: Compute top-10 equal-weight portfolio targets
**As a** portfolio operator, **I want** the 10 publicly-traded clients with the
highest total quarterly lobbying spend (income paid to firms + in-house
expenses) as an equal-weight target portfolio **so that** I can replicate the
"Top Lobbying Spenders" strategy.
**Points:** 3
**Status:** Done
**Acceptance criteria:**
- [x] Given cached filings for a quarter, when the signal runs, then each
      client's spend = sum(income) + sum(expenses) across all their filings in
      that quarter. *(Verified: unit test `test_aggregate_combines_firm_and_in_house_filings`
      + live 2026Q3 run: HII $11.32M across 2 filings.)*
- [x] Given ranked spenders, when only mapped (public) companies are available,
      then exactly the top 10 by spend are selected, each at 10% weight.
      *(Verified live: 10 holdings, weights sum 1.0000; unit
      `test_build_targets_capped_at_size_and_equal_weight`.)*
- [x] Given fewer than 10 mapped companies, when the signal runs, then weights
      sum to 1.0 across however many are available. *(Verified:
      `test_build_targets_fewer_than_size_sums_to_one`.)*
- [x] Given ties in spend at the cutoff, when selecting, then the tie is broken
      deterministically (alphabetical by client name) and noted in the output.
      *(Verified: `test_rank_breaks_ties_alphabetically`; ties surfaced in
      `state.spend_ties_at_cutoff` and rendered in the dashboard notes.)*

**Known limitation (not in scope of this story):** subsidiary rollup is not
implemented — each LDA client name is treated as a separate company (e.g.
multiple Amazon/Alphabet entities would count separately). Tracked as part of
the backtest epic in the icebox.
