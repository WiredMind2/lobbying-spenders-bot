### US-001: Cache quarterly LDA filings locally
**As a** quant developer, **I want** a CLI that downloads all LD-2 quarterly filings
for a given year/quarter from the LDA API into a local cache **so that** the signal
can be computed without re-hitting the API on every run.
**Points:** 5
**Status:** Done
**Acceptance criteria:**
- [x] Given `python run_ingest.py --year 2026 --quarter 3`, when the command
      finishes, then `data/raw/2026Q3.jsonl` exists and contains >10,000 records.
      *(Verified 2026-11-19: 21,825 filings; API reported count 21,824 — one late
      filing posted mid-run.)*
- [x] Given the cache file already exists, when ingest runs again, then it is not
      re-downloaded unless `--refresh` is passed. *(Verified: reruns completed in
      seconds off the cache.)*
- [x] Given a downloaded filing set, when parsed, then each cached record carries
      client name, registrant name, income, expenses, and posted date. *(Verified
      via aggregation debug script over the cache.)*

**Implementation notes:** the LDA API hard-caps results at 25/page and its `next`
links can silently terminate early under rate-limit pressure, so paging is by
explicit page number with 429 backoff honoring `Retry-After`; duplicates (from
ordering shifts mid-run) are removed by filing UUID.
