### US-001: Cache quarterly LDA filings locally
**As a** quant developer, **I want** a CLI that downloads all LD-2 quarterly filings
for a given year/quarter from the LDA API into a local cache **so that** the signal
can be computed without re-hitting the API on every run.
**Points:** 5
**Status:** Ready
**Acceptance criteria:**
- [ ] Given `python run_ingest.py --year 2026 --quarter 3`, when the command
      finishes, then `data/raw/2026Q3.jsonl` exists and contains >10,000 records.
- [ ] Given the cache file already exists, when ingest runs again, then it is not
      re-downloaded unless `--refresh` is passed.
- [ ] Given a downloaded filing set, when parsed, then each cached record carries
      client name, registrant name, income, expenses, and posted date.
