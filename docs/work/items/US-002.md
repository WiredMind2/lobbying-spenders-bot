### US-002: Map lobbying clients to stock tickers
**As a** quant developer, **I want** each top lobbying client resolved to a US
stock ticker via EDGAR plus a manual override table **so that** only
publicly-traded companies enter the portfolio.
**Points:** 5
**Status:** Ready
**Acceptance criteria:**
- [ ] Given EDGAR's `company_tickers.json` is reachable, when mapping runs, then
      a local copy is cached under `data/`.
- [ ] Given a client name that exactly or fuzzily matches an EDGAR company, when
      mapping runs, then a ticker is assigned with the match method recorded.
- [ ] Given a client listed in `mappings_overrides.csv`, when mapping runs, then
      the override wins over any fuzzy match.
- [ ] Given an unmatchable client (association, union, private), when mapping
      runs, then it is excluded from the portfolio and surfaced as "unmapped".
